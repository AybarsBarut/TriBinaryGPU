### Scientific Conclusions from Effect Decomposition:
1. **Separating Math from Hardware (Hypothesis H2 / Control GPU-BT):**
   - Running balanced-ternary arithmetic on binary hardware (**GPU-BT**) is universally inferior: it consumes **~1.58x MORE energy** than standard binary. Wasting $2 - 1.585 = 0.415$ bits per trit doubles register and datapath width without providing native multi-valued switching advantages.
   - However, **native ternary hardware (GPU-T)** achieves an energy ratio of **0.36x to 0.44x** relative to GPU-BT.
   - The total effect ($T / B = 0.57x$ on GEMM, $0.65x$ on BitNet) is therefore **strictly a hardware cell and interconnect advantage**, not an arithmetic encoding artifact!
2. **Quaternary MLC Isolation (Decision Q8):**
   - The multi-level memory gain is exactly isolated ($Q2b / Q1b = 1.0$ in logic-dominated workloads), proving that multi-level memory density gains do not improperly credit logic radix.
